# 12주 시나리오 커리큘럼

1주차와 12주차는 같은 시나리오라서 성장을 비교할 수 있다.

| 주차 | 시나리오 | 연습 포인트 |
| --- | --- | --- |
| 1 | 분석 SDK 마이너 배포 후 iOS 웹뷰에서 결제 버튼이 반응하지 않음 | 완화 우선, unpublish 대신 이전 코드로 새 버전 배포 |
| 2 | 디자인 시스템 패치 배포 후 특정 안드로이드 웹뷰에서 레이아웃이 깨짐 | 브라우저 지원 범위, 시각적 회귀 감지 |
| 3 | 새 배포 직후 일부 사용자에게 흰 화면, 청크 로드 실패 | CDN 캐시, HTML과 해시된 파일의 불일치, 이전 자산 보존 |
| 4 | 모노레포 CI가 갑자기 전부 실패, 외부 의존성이 레지스트리에서 사라짐 | left-pad 유형, 의존성 미러링, lockfile 무결성 |
| 5 | 공용 의존성에 악성 버전이 배포됐다는 소식 (메인테이너 계정 탈취) | 공급망 보안, 영향 범위 파악, 빌드 산출물 감사 |
| 6 | 인증 클라이언트 업데이트 후 대량 로그아웃, 토큰 형식이 바뀌어 롤백이 어려움 | 되돌릴 수 없는 변경, 백엔드와의 협업 |
| 7 | 피처 플래그 서비스 장애로 미완성 기능이 노출됨 | 기본값 설계, 실패했을 때 안전한 쪽으로 동작하기 |
| 8 | 에러 없이 전환율이 2주에 걸쳐 서서히 하락, 원인은 번들 크기 증가 | 느린 장애 감지, 성능 예산 |
| 9 | 서드파티 스크립트가 메인 스레드를 막아 결제 페이지가 느려짐 | 외부 의존성 격리, 타임아웃 |
| 10 | iOS 새 버전 출시 당일, 웹뷰 동작이 바뀌어 특정 기능이 오작동 | 우리가 배포하지 않은 장애, 대응 범위 정하기 |
| 11 | AI 에이전트가 올린 PR이 린트 설정을 바꿔, 규칙이 꺼진 채 머지됨 | 검사 기준 변경 리뷰, CODEOWNERS |
| 12 | 1주차 시나리오 재도전, 3단계 조직 확산까지 진행 | 성장 비교, 다른 팀 적용과 성과 측정 |
