## 5가지 컨셉

### 1. 포스트 위 인터랙티브 데모 임베드 ★사용자 관심 표명
글 본문 안에 `<Demo />` MDX 컴포넌트로 살아있는 데모를 넣는다. 코드 패턴 시연 / 알고리즘 시각화 / 번들러 동작 미리보기 등.

```mdx
<Demo title="esbuild plugin 호출 순서" lazy>
  <ResolveLoadDemo />
</Demo>
```

- 본문 안에 인라인. 카드 형태, marker-300 좌측 보더, "▶ 인터랙티브" 라벨.
- lazy mount (스크롤 진입 시) — 초기 페이지 무게 보호
- demo는 `components/demos/<name>.tsx`에 React 컴포넌트로 작성
- TOC에서 "▶ 데모: …" 으로 별도 표기

**구현 난이도**: 중. MDX 컴포넌트 매핑 + lazy boundary + 데모 1개 시범.

### 2. 시리즈 진행률
글 상세 헤더에 같은 시리즈의 진행률 표시 (`01 / 5` + 점선 도트들).
시리즈 인덱스 페이지(`/series/[id]`) 추가 — 같은 시리즈 글들을 순서대로 + 시리즈 소개 글.

**구현 난이도**: 낮음.

### 3. TIL / 짧은 메모
긴 글이 아닌 1-3 단락짜리 짧은 메모를 별도 섹션 (`/til`)으로.
홈에서 "오늘의 메모" 작은 카드 노출.

**구현 난이도**: 낮음. MDX frontmatter `type: 'til'` 분기.

### 4. Now 페이지
`/now` — "지금 뭐 하고 있는지" 한 페이지 (nownownow.com 컨벤션).
지금 일하는 회사, 지금 읽는 책, 지금 빌딩 중인 사이드 프로젝트.

**구현 난이도**: 매우 낮음. 정적 MDX 1개.

### 5. ⌘K 글로벌 검색
`Cmd+K` 다이얼로그. 글 제목/태그/시리즈 fuzzy 검색.
키보드 네비 (↑↓ Enter Esc).

**구현 난이도**: 중. cmdk 라이브러리 권장.
